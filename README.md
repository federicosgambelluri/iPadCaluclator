Calcolatrice per iPad

Un’alternativa gratuita e senza pubblicità alla calcolatrice ufficiale di Apple per iPad!

Questo repository contiene il codice della mia Calcolatrice per iPad, sviluppata con HTML, CSS e Vanilla JavaScript.

📌 Perché ho creato questa app?
Fino al rilascio di iOS 18, Apple non ha mai fornito una calcolatrice ufficiale per iPad. Questo mi ha spinto a creare una soluzione alternativa, completamente gratuita e senza pubblicità, ispirata al design originale della calcolatrice di Apple per iPhone.

🔹 Caratteristiche della calcolatrice:
	•	Interfaccia fedele al design Apple 🍏
	•	Funzionamento fluido e immediato
	•	Nessuna pubblicità o acquisto in-app 🚀
	•	Completamente gratuita e open-source

📌 Sfide Extra (per chi vuole migliorare il codice)

Se vuoi contribuire o migliorare l’app, ecco alcune idee per renderla ancora più performante:
✅ Abilitare l’input da tastiera: rendi la calcolatrice compatibile con la digitazione tramite tastiera fisica.
✅ Limitare il numero di cifre visibili a 9: evita che numeri troppo lunghi sforino lo schermo.
✅ Adattare dinamicamente la dimensione del font: regola la grandezza dei numeri in base alla lunghezza (per 6, 7, 8, 9 cifre).

🛠️ Come utilizzare il codice

Puoi utilizzare questo codice liberamente per i tuoi progetti personali!
Per visualizzare l’app localmente:
	1.	Scarica i file dal repository
	2.	Apri index.html in un browser
	3.	Inizia a calcolare! 🎉
